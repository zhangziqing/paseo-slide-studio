# 验证记录

运行版本为 Slide Studio 0.2.0，宿主为 Paseo 0.15.0。内置画布曾在真实 Paseo 网页客户端中通过以下检查：

- 工作区面板和 HTML 文件标签页直接打开幻灯片。
- 缺失文件显示错误，已有画布可继续使用。
- Unicode 路径、相对 SVG、srcset、字体、链接 CSS 和循环样式导入。
- 文字编辑、撤销重做，以及移动带图片背景的对象。
- 保存后的内容正确，备份与修改前内容完全一致，相对资源路径保持原样。
- 外部修改触发版本冲突，过期内容无法覆盖文件。
- 深浅主题、390 px 网页布局、画布重建后的草稿恢复。
- 编辑中的标签页显示未保存标记，关闭时询问，取消后保留画布。
- 阻断独立编辑器端口后仍可编辑；没有独立端口请求，也未打开新的浏览器页面。

文件层集成测试包含 6 项，使用临时生成的文稿和 Python stdio 进程，覆盖备份与冲突、路径与符号链接边界、资源类型、多个工作区、Python 启动失败、无网络监听和进程退出清理。运行 `npm run check` 可复查这些测试、TypeScript 类型和生成文件一致性。

分发仓库不包含测试截图、实际演示文稿、主机标识或当时的机器日志。Electron 二进制、实体 iOS/Android 和跨机器连接尚未实测。窄屏验证来自网页客户端，原生手机端暂不提供编辑画布。
